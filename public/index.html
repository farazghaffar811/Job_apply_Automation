Applying with Claude in Chrome

  1. Fill in Profile & resume and import your companies.
  2. Install the Claude in Chrome extension and stay signed in to LinkedIn in that Chrome window.
  3. Paste the prompt below into Claude Code.
  4. Claude opens each company's careers page, finds roles that match, fills the form and marks the row Ready for review.
  5. You check each one and approve the submit. Rows that need an account or a CAPTCHA are marked Needs you.
